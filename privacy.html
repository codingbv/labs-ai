개인정보처리방침

Labs AI는 연구소 내부 직원이 사용하는 사내 업무 비서 시스템입니다. 일반 이용자를 대상으로 가입 서비스를 제공하지 않으며, 이용자는 연구소 소속 직원으로 한정됩니다.

데이터 흐름

Labs AI는 연구소 내부 시스템이 관리하는 부서 업무 일정을 직원의 Google Calendar로 내보내는(export) 연동을 수행합니다. 직원이 직접 만든 캘린더의 일정 내용은 읽어 오거나 수집하지 않습니다.

요청하는 Google Calendar 권한과 사용 목적

  • calendar.app.created: 부서 업무용 보조 캘린더를 생성·삭제하고, 앱이 생성한 캘린더에 업무 일정을 생성·수정·삭제합니다. 일정에는 업무 참여자를 참석자로 추가하여 참여자의 캘린더에 일정이 표시되도록 합니다. 참석자의 일정 수정 권한은 부여하지 않습니다.
  • calendar.calendarlist.readonly: 앱이 생성한 업무용 캘린더를 이름으로 찾기 위해 캘린더 목록을 조회합니다. 목록 중 앱이 생성한 캘린더 외의 항목은 저장하거나 다른 용도로 사용하지 않습니다.
  • calendar.events.public.readonly: 업무 일정 배치 시 휴일을 반영하기 위해 공개 캘린더인 대한민국 공휴일 캘린더를 조회합니다.

일정의 참석자 정보는 연구소 내부 시스템의 업무 데이터에서 가져온 직원 이메일 주소이며, Google에서 수집한 정보가 아닙니다.

저장하는 Google 사용자 데이터

내보낸 일정을 다시 갱신하거나 삭제하기 위해, 앱이 생성한 캘린더와 일정의 식별자(ID)만 연구소 서버에 저장합니다. OAuth 인증 토큰은 접근 권한을 제한하여 연구소 서버에 보관합니다.

정보 공유 및 이용 제한

Google API를 통해 얻은 데이터(캘린더 목록, 캘린더·일정 식별자, 인증 토큰 등)는 일정 내보내기 기능에만 사용합니다. 이를 제3자에게 판매하거나 공유하지 않고, 광고 목적으로 사용하지 않으며, 외부 AI 서비스로 전송하거나 AI 모델의 개발·개선·학습에 사용하지 않습니다. Labs AI가 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 Limited Use 요구사항을 포함한 Google API Services User Data Policy를 준수합니다.

Google Calendar로 내보내는 업무 일정의 원본은 연구소 내부 시스템의 데이터이며, 그 처리에는 연구소 내부 정책이 적용됩니다.

보관과 삭제

서버에 저장한 식별자와 인증 토큰은 업무 수행에 필요한 기간 동안 보관하며, 직원이 퇴사하거나 삭제를 요청하면 지체 없이 삭제합니다. Google Calendar로 내보낸 캘린더와 일정은 직원이 Google Calendar에서 직접 삭제할 수 있습니다.

접근 권한 철회

Google 계정의 연결된 앱 관리 (myaccount.google.com/connections)에서 Labs AI의 접근 권한을 언제든지 철회할 수 있습니다. 철회 후에는 일정 내보내기가 동작하지 않습니다.
